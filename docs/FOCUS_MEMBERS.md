# 重点成员关注

在每个明确选择的群内关注指定账号，并在长图中展示独立关注区。它整理本人本时段的主要观点、关注标的与理由、实际观点变化和明确提出的观察条件，不把关注对象当成权威或跟单依据。

先核对身份，避免同名误认：

```bash
wechat-pulse groups --prefix '研究'
wechat-pulse members --group-id '明确选择的群ID@chatroom' --search '群昵称'
```

`members` 只返回指定群成员，包含没有设置群内昵称的账号；这些成员使用本机最新同步的联系人昵称。多个同名匹配时由使用者确认，不能只选第一项。稳定账号 ID 只放私有配置，不能提交到公开仓库。

在已有配置中添加关注列表，保留现有模型、群与密钥配置：

```json
{
  "focus_members": [
    {
      "group_id": "明确选择的群ID@chatroom",
      "sender_id": "members返回的账号ID",
      "display_name": "确认时的昵称"
    }
  ]
}
```

账号和群 ID 联合绑定身份。改昵称后继续关注该账号，并优先显示最新同步昵称；`display_name` 仅在本时段没有发言且无法读取当前昵称时备用。不同账号同名不会合并，同一账号在别的群发言也不会自动纳入。`focus_members` 本身不授权读取新群，报告的 `--group-id` / `groups` 仍需明确选择。

关注区的每条结论必须引用该账号在指定群的真实发言或图片。转发、引用回复和图片中的他人观点不自动归给发送者；持仓/交易仅为群友自述。确认观点变化需要至少两个不同时间点的本人证据；没有新消息不代表转空、空仓或改变策略。这里只比较本报告时段，不声称已经建立跨日交易履历。

本机未同步到发言时显示“未同步到”，不编造观点。只有语音、未解析附件或回流报告等内容时标明没有可用独立材料。模型失败会保留整体群聊总结，并显示关注卡未完成；不偷偷把脚本摘录当成模型分析。

默认关注卡沿用所选模型，图片解读复用原报告的视觉结果，不重复发图。长文本先分段归纳并校验证据。原文未变时复用关注分析缓存，改名只更新显示。`rules` 只展示有来源的原文摘录，不请求大模型；原有离线约束不变。

同时启用 [标的补查](MARKET_RESEARCH.md) 时，关注卡中出现的标的也进入缺失依据检查。外部资料仍单独标注，不改写成关注对象本人给出的观点。查看 HTML 附录可追溯每条关注结论的原文依据。

编程助手应先确认群与账号，保存私有配置，然后运行所需报告并检查 `focus_members[].status`、昵称和引用。不要把关注者或群友身份、真实发言、缓存和报告放进提交或 issue。代码的测试使用虚构账号验证同名隔离、跨群隔离、改名缓存、无发言与错误引用。
