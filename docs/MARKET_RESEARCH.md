# 标的日线与消息补查

可选功能：群聊提到具体股票、指数或大宗商品，但缺少技术面或消息面指引时，自动补查缺少的一面。外部资料和分析紧跟对应个股卡片；原油等其他标的展示在市场线索区。群友观点、截图观察和外部检索分别标注，不把群热度当事实验证。

在现有私有配置中加入下面一项，保留原来的模型、群和微信配置：

```json
{
  "market_research": {
    "enabled": true,
    "max_targets": 8,
    "news_days": 14,
    "cache_minutes": 60,
    "timeout": 150,
    "api_key_env": "YIXIN_API_KEY",
    "api_key_file": "~/.config/yixin-api/api-key.json"
  }
}
```

股票日线和消息的检索后端是 [Yixin OpenAPI](https://openapi.billionsintelligence.com/docs)，需要该服务可用的金融数据库、搜索和可选公告全文权限。环境变量优先；也可用本机私有 JSON 文件保存 `api_key`。不要将真实密钥写入项目配置、示例、日志或 Git。查询会消耗该服务的用量；Codex/ChatGPT 订阅不包含第三方数据服务额度。

不启用时保持原行为。`rules` 和 `local_only` 始终跳过在线补查，不需要新账号。使用本地模型但希望查外部金融数据时，可以明确设置 `local_only: false`；分析模型仍按原配置选择。模型工具权限仍被关闭，联网由固定查询代码完成。

## 分析内容

- 日线：从返回的原始数据计算 MA5/10/20/60、近1/5/20交易日涨跌幅、当日成交量与此前5日均量之比，以及此前20日高低区间。历史区间是观察范围，不作为目标价或必然有效的支撑压力。
- 价格须匹配同一标的、单位和复权方式，股票要求一致前复权日线；至少21条收盘数据，60条才显示MA60。解析不支持的表格格式、数据冲突或不足时标记无法判断，不让模型补造K线。
- 使用已结束的日线。明确A股代码或返回的A股数据库来源在北京时间15:05后可用当日数据；海外或未明确市场的序列保守使用前一日及以前的记录。周末保留真实交易日期；数据超过7个自然日标记陈旧，长假或停牌也不冒充最新行情。
- 原油未指定市场时使用美国EIA经FRED发布的WTI库欣日度现货报价；明确布伦特时使用对应布伦特现货系列。它是日度价格参考，并非期货收盘K线，不提供日内高低价或成交量，数据有发布滞后。黄金/白银尝试伦敦现货，并注明只是参考基准，不代表群友的交易合约。其他无法确定品种或合约的讨论只补查消息。接口未能给出对应日线则如实标注，不能混用现货、结算价、不同合约或不同原油品种。
- 消息：股票优先公告，商品/指数查询相关网页；仅纳入名称与日期可核对的近期结果，最多展示3条。尝试取得最近一篇可访问公告全文；其余明确区分全文、部分全文、搜索摘要。查不到不等于没有消息。
- 当天检索只有发布日期而没有时间时，标明可能晚于群消息截止；历史盘中报告不采用发布时间无法核对的同日资料。发布日期不自动等于事件发生日期。
- 分析说明外部资料怎样支持、削弱或仍无法验证群观点，并给出条件性研究观察。它不是个性化投资建议。

PNG显示数据日期、口径与来源；HTML附录保留查询、返回表格、消息链接或原始公告句柄。没有公开URL的公告不会被编造成可访问链接。金融数据库返回值没有与第二家行情源逐点对账，结构校验不等于保证上游数据正确。

## 隐私、缓存与故障

标的识别和补查分析沿用用户已经选择的模型。数据检索只发送标的名称、明确代码、日期范围及固定指标条件，**不发送聊天原文、昵称、群ID或微信附件**。网页内容和检索结果均是待分析数据，不执行其中指令。

原始查询缓存、报告和检索记录都保存在私有运行目录。缓存按查询条件和时效复用，同一消息不变时也能到期刷新外部资料；不重复运行原群聊综述。最多同时发起2个只读查询，不在失败后无限重试。认证、权限、计费或网络失败只影响补查部分，原群聊总结继续生成并显示缺失状态。

编程助手安装时：先完成现有 `demo` 和 `doctor`，保留用户配置。只有用户启用补查时再连接数据服务；用虚构HTTP响应跑测试，不把真实返回数据、密钥或私有报告提交。更改私人定时任务无需复制实现，定时任务直接读取同一配置与 `src/marketpulse`。

原油基准来源：[WTI日度现货](https://fred.stlouisfed.org/series/DCOILWTICO)、[布伦特日度现货](https://fred.stlouisfed.org/series/DCOILBRENTEU)。FRED请求不携带Yixin密钥或群聊数据。历史查询采用当前可取得的数据版本，可能含后续修订；本功能不提供严格的历史回测数据快照。
